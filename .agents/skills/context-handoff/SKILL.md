# Context handoff

1. Read the [context rules](../../rules/CONTEXT_MANAGEMENT.md) and compare [project state](../../context/PROJECT_STATE.md) with the diff, decisions, and results. Update it for meaningful progress.
2. If more detail is needed to resume, write a short handoff covering the request, completed work, affected files, durable discoveries, linked decisions, exact checks and outcomes, blockers, and next action.
3. Keep decisions in their authoritative documents. Remove redundant carryover through consolidation and keep private data and conversation transcripts out of shared artifacts.
