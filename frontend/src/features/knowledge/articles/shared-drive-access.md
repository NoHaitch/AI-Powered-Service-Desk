## Prepare your request

- Confirm the drive name and folder path with the team that owns it.
- Specify whether you need to view files or edit them.
- Include your business reason and the deadline, if there is one.

## Request access

Open the shared-drive request below and enter the folder name and justification. Keep the request focused on the folder you need so its owner can review the appropriate level of access.

If you previously had access and it suddenly stopped working, report an incident with the exact error and when you last accessed the folder.
