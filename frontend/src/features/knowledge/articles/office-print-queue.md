updated: 2026-11-27

## Locate the job

Confirm you selected the correct printer or secure release queue. Check whether the job is still listed on your device and whether it shows a message. If the queue requires a badge or another approved release method, check the station before sending more copies.

### Use the status to choose a next step

| Visible status | What it may mean | What to do |
| --- | --- | --- |
| Paused on your device | The local queue is waiting | Resume it if permitted |
| Waiting for release | The printer expects you to collect it | Follow the release instructions |
| Printer unavailable | The device or print service may be offline | Record the printer location and ask if others are affected |

## Try a safe reproduction

1. Cancel only your own duplicate jobs.
2. Try printing one non-sensitive test page to the same queue.
3. If the test works, check the paper size and format of the original document.
4. If the test fails, capture the exact queue name and error for support.

### What to include in the ticket

- Printer name or asset tag and office location.
- Exact queue status and the result of the test page.
- Whether coworkers can print to the same device.

Leave confidential document content out of the ticket.
