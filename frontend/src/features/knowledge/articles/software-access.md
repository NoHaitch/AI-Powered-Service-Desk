## Find the right application

Confirm the application name with your team. Check whether your organization provides the software through an approved company portal.

## Submit the request

- Enter the application name and the work you need to do in it.
- Specify the role or permissions you need, if known.
- Include a work deadline and any known license requirements.

If an application you already use stops opening, submit an incident with its name, the error, and what changed.
