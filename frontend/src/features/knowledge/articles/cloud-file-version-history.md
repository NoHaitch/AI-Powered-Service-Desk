title: Recover a previous version of a shared file
updated: 2026-11-27

summary: Find an earlier version and protect teammates' changes before restoring it.

## Identify the correct copy

Start from the shared workspace where the team normally edits the file. Look for other files with similar names and compare their folders, owners, and last modified times. If you opened a local download, return to the shared original before looking for version history.

### Choose how to recover it

| Situation | Suggested action | Reason |
| --- | --- | --- |
| Only a paragraph is missing | Open the earlier version and copy the relevant text | Preserves newer edits |
| A replacement overwrote the file | Discuss a restore with the file owner | Restoring changes what teammates see |
| The file was deleted | Check the workspace recycle bin | Version history may be unavailable from the original link |

## Review before restoring

1. Open the file's version history and find the last version with the missing content.
2. Compare that version with the newest copy and confirm who has been editing.
3. If the entire file must be restored, agree on a time with the owner and alert active collaborators.
4. Reopen the shared link and verify the restored content with the owner.

### Escalate if the version is unavailable

Provide the original location, file owner, approximate change time, and any version identifiers you can see. Avoid including the file itself in a support ticket unless an approved channel requires it.
