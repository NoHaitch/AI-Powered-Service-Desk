## Collect the basics

Ask the hiring manager for the start date, team, work location, and primary contact. Confirm whether the employee will work remotely or from an office and who will receive the device. Use the approved onboarding channel for personal information.

### Assign an owner to each request

| Request | Details to provide | Typical coordinator |
| --- | --- | --- |
| Laptop and accessories | Work location, delivery needs, and required equipment | Hiring manager |
| Application access | Application names, roles, and business purpose | Application owner |
| Shared folders and groups | Exact folder or group names and required access | Team owner |

## Run first-day checks

1. Confirm the starter can sign in and complete enrollment using the approved setup instructions.
2. Check email, the calendar, meeting audio, and access to team resources.
3. Ask the starter to verify that they can perform a typical work task in each required application.
4. Record any missing access separately so it can reach the right owner.

### If access is delayed

Provide the application name, the business activity blocked, and the start date in the support request. Keep passwords and onboarding codes out of ordinary tickets.
